## Setup
- Git: `origin` is the remote above, branch `main`. `.env`, `.venv/`, `node_modules/`, `__pycache__/` are gitignored.
- Backend: Python 3.12 venv at `backend/.venv`, packages in `backend/requirements.txt` (fastapi, uvicorn, sqlalchemy, alembic, psycopg2-binary, pgvector, ollama, pytest, plus PyJWT and pwdlib[argon2] for auth, and gunicorn + uvicorn-worker for the container). Run Alembic from `backend/`.
- FastAPI app: `backend/app/main.py` includes one router per feature: `auth` (`/api/auth`), `conversations` (`/api/conversations`, the only one with endpoints so far), `stream` (`/api/stream`), `export` (`GET /api/conversations/{id}/export?format=md|json`, files built in `services/export.py`), `stats` (`/api/users`, `GET /api/users/{user_id}/stats`, DB code in `repositories/stats.py`, 403 for another id); `stream` has `POST /api/stream` (SSE, schema `schemas/stream.py`; since 2026-11-24 it answers with RAG: `services/rag.py` `retrieve_chunks` + `build_prompt` (system message with the chunks, user message with the question), then `services/llm.py` `stream_chat`; the answer is saved with `sources` and the `done` event carries them); database logic in `app/repositories/conversations.py` (user's choice: `repositories/` holds DB code, `services/` stays for llm/rag/export/cache), schemas in `app/schemas/conversations.py`.

Code: `src/api/` (client.js, auth.js, conversations.js, stream.js = `POST /api/stream` via fetch + ReadableStream with buffering), `src/hooks/useStream.js` (streaming state, `start`/`stop` with AbortController), `src/api/stats.js`, `src/components/` (Sidebar, ChatWindow, MessageBubble, Icons, StatsDashboard), `src/pages/` (LoginPage, ChatPage, DocumentsPage, StatsPage), `src/utils/time.js`, styles in `src/index.css` (imports `src/tokens.css` = every colour/font/size/spacing token, and `src/base.css` = Hallmark base rules). Layout from the user's picture (sidebar = profile, Home (chat), Documents (upload layout), Chats list, Settings); look since 2026-11-12 = Hallmark theme Ribbon "two-in-the-morning" (blue-black night, warm off-white text, one amber accent, Instrument Sans titles over Figtree). Hallmark skill is installed globally; its records live in `.hallmark/`.
